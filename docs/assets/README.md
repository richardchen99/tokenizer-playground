# Documentation figures

All screenshots are captures of the running [Tokenizer Playground](https://richardchen99.github.io/tokenizer-playground/) using public built-in examples. They show application content only and are also used in the [project research note](https://richardchen99.github.io/blog/tokenizer-playground-note/). Capture date: **2026-09-18**.

| File | Captured state |
| --- | --- |
| [`overview.jpg`](overview.jpg) | Classic words; five learned merges |
| [`history.jpg`](history.jpg) | Ordered merges: `e + s` (9), `es + t` (9), `est + </w>` (9), `l + o` (7), `lo + w` (7) |
| [`chinese.jpg`](chinese.jpg) | Chinese research; six merges; `金融研究者` encoded as `金融 / 研究 / 者`; lossless reconstruction |

[`architecture.svg`](architecture.svg) is an original, editable vector schematic prepared for this repository. [`architecture.png`](architecture.png) is its 3,200-pixel-wide raster export. It separates weighted training counts from ordered-rule encoding; see the [README](../../README.md#mathematical-scope) for the overlap and Unicode conventions.

No screenshot is a synthetic interface image. The framework diagram is drawn with vector shapes and text, not generated by a text-to-image model. Figures contain no editor windows, browser chrome, local paths, or private account details. Numerical values illustrate the stated experiment and are not performance benchmarks.
